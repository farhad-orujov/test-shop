# CTF — Stored XSS Challenge

## Overview

This is a beginner-friendly CTF challenge built into the test-shop application. Your goal is to obtain the admin key by exploiting a vulnerability in the product comments feature.

## Objective

Discover the admin key using the product page functionality. Once you have the key, use it to complete the final step.

## How to Play

1. Visit the hosted site in your browser.
2. Explore the product catalog and investigate the comments section.
3. Find a way to obtain the secret admin key.

## Completion

After obtaining the key, use it to finish the challenge on the dedicated page.

## Important

- This lab contains a deliberate vulnerability and is intended for educational use only.
- Do not attempt to attack or exploit any systems outside this environment.
- After finishing, the vulnerability should be closed or comments cleared.

## What You'll Learn

- How to find and exploit Stored XSS
- Basic security practices: output encoding, Content Security Policy, HttpOnly cookies
